# Native learning and memory

Teach and Deep Training use `src/learning/native-learning.js`, called synchronously by the shared gameplay reducer inside the existing IndexedDB transaction. There are no AI services, model downloads, runtime npm dependencies or backend inference. The removed AI Model Lab and browser-model experiments are not application routes or production imports. The page and rendering assets still need to load normally; this is not an offline-installable application guarantee.

`text.js` provides Unicode normalization, word/sentence segmentation, lexical features and conservative input checks. `knowledge.js` derives term document frequencies, observed sentence co-occurrences and ranked retrieval from saved memory content. A disposable, content-bound cache avoids changing legacy records. Native records include original sentences, keywords, provenance, unverified status, classification confidence and previously observed associations. Co-occurrence is not a factual relationship.

Exact normalized repeats reinforce the original with zero XP. High lexical overlap, possible numeric/negation conflicts and mixed old/new sentences return uncertainty without learning charges or rewards. Other related claims remain separate. Category names are saved labels or neutral lexical excerpts (`Notes: …`); they are not guessed scientific classifications. The existing XP schedule remains: concept 50, understanding 75, daily cap 500. A lexical connection to multiple existing memories with observed associations can receive the understanding classification; it does not mean factual verification. The correction reward remains in the rules but native learning never automatically corrects or supersedes a memory.

Both the production and isolated sandbox UI use the same reducer. Energy, shared cooldown, life stimulation, progression and canonical neural growth still use existing rules. Memory retrieval can quote a stored claim in Talk; it does not generate an answer or explanation. Development uses lexical cohesion and saved categories instead of provider vectors.

No IndexedDB schema migration is required. Existing IDs, content, categories, embeddings, provider-specific indexes, provenance and historical correction/reinforcement fields remain stored. Old model metadata is never read, deleted or rewritten. Native metadata is additive on new records and aggregate summaries; a repeat changes only the established reinforcement fields. The graph is recoverable from canonical memory text after reload.

Limitations: lexical matching is not semantic understanding or fact checking. It can miss paraphrases, synonyms and contradictions, and reject distinct statements with similar wording. Unicode segmentation uses the browser's Intl implementation with a basic fallback; quality differs across languages and versions. Input is bounded at 2,000 characters/eight sentences and the existing 1,000-memory cap remains. Deliberate paraphrase farming cannot be guaranteed absent without semantic knowledge; client state is not anti-cheat authority.
